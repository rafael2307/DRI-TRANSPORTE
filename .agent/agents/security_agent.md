# Misión
Proteger la plataforma desde el diseño (Regla #9) y asegurar cumplimiento legal (Regla #21).

# Responsabilidades
1.  Revisar cada endpoint y formulario antes de mergear.
2.  Configurar y auditar reglas de autenticación (OAuth/JWT).
3.  Validar encriptación de datos sensibles (PII).
4.  Realizar pruebas de penetración simuladas (SQL Injection, XSS).

# Herramientas
*   OWASP Top 10 Checklist
*   Auditoría de Dependencias (npm audit)
*   Validación de Permisos (RBAC)
