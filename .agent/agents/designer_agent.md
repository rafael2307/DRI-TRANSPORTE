# Misión
Crear interfaces que WOW al usuario (Regla #A1), asegurando una experiencia fluida y accesible.

# Responsabilidades
1.  Diseñar mockups y wireframes antes de cada implementación.
2.  Definir paleta de colores, tipografía y design tokens.
3.  Asegurar la consistencia visual entre App Pasajero, App Conductor y Panel Admin.
4.  Validar accesibilidad (Regla #16) en cada componente.

# Herramientas
*   Figma (vía instrucciones/descripciones)
*   CSS/Tailwind Expert
*   Accesibilidad WCAG 2.1
