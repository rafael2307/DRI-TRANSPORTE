# Sistema de Apps de Transporte

Este repositorio contiene el código fuente para la plataforma integral de transporte.

## 📜 Reglas del Proyecto
Este proyecto se rige estrictamente por las **17 Reglas Maestras** definidas en [REGLAS_DEL_PROYECTO.md](./REGLAS_DEL_PROYECTO.md).

## 📂 Estructura del Proyecto
*   **backend/**: API REST/GraphQL y WebSocket (NestJS).
*   **app-pasajero/**: Aplicación móvil para usuarios (Flutter/React Native).
*   **app-conductor/**: Aplicación móvil para socios conductores.
*   **panel-admin/**: Dashboard web para administración (Next.js).

## 🚀 Empezando
1.  Clonar el repositorio.
2.  Leer `REQUISITOS.md`.
3.  Seguir las instrucciones de instalación en cada subcarpeta.

## 🤝 Colaboración
*   Todo PR debe ser revisado por un par (**Regla #10**).
*   Todo código debe tener tests (**Regla #6**).
*   Commits deben seguir la convención establecida (**Regla #7**).
