¿Cómo levantar el entorno?

Abre 4 terminales separadas en el directorio raíz y ejecuta:

Terminal 1: cd backend && npm run start:dev Terminal 2: cd panel-admin && npm run dev Terminal 3: cd app-pasajero && npm run web Terminal 4: cd app-conductor && npm run web
